# Wanderlust

Wanderlust is a travel-listing website built using HTML, CSS, JavaScript, and Bootstrap. It displays travel listings in a responsive card layout.

## Features

- Responsive navigation bar.
- Responsive listing-card grid.
- Pagination with **9 cards per page**.
- Listing cards display title, image, location, country, and price.
- Add New Listing form.
- Sign-in modal interface.
- Sample listing data stored in `data.js`.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## Project Structure

Wanderlust/
├── index.html
├── style.css
├── app.js
└── data.js

| File | Description |

| `index.html` | Main page structure |
| `style.css` | Website styling |
| `app.js` | Listing display, pagination, and front-end interactions |
| `data.js` | Sample listing data |

## Getting Started

1. Clone or download this repository.
2. Keep all four project files in the same folder.
3. Open `index.html` in a web browser.

You can also open the project in Visual Studio Code and use the Live Server extension.

## Pagination

Listings are displayed in groups of up to **9 cards per page**. Use the pagination controls to navigate between pages.

## Current Project Status

- The website currently uses sample data from `data.js`.
- Listing descriptions are not displayed on the cards.
- The Add New Listing form dynamically adds listings in the browser, but does not save them permanently.
- The sign-in modal is currently a front-end interface; authentication has not been implemented.
- Backend and database integration have not yet been implemented.
